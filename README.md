# Ahmed-Deaf-11

واجهة ويب عربية للتواصل مع الصم:

- كتابة أو لصق رسالة من Google Keyboard.
- عرض كلمات الرسالة بالتتابع مع دعم مقاطع فيديو ASL محلية.
- كتابة مباشرة من الصوت.
- تشغيل كاميرا الجهاز.
- مشاركة النص عبر WhatsApp وMessenger وأزرار Instagram.

## التشغيل

افتح `index.html` عبر GitHub Pages أو خادم محلي، ثم اسمح بالميكروفون والكاميرا. أنشئ مجلد `videos/` وأضف مقاطع مرخّصة مثل `hello.mp4` و`thanks.mp4` ثم عدّل قاموس `clips` في `script.js`.

## حدود مهمة

هذا الإصدار يعرض الكاميرا ولا يترجم ASL تلقائياً. الترجمة المباشرة تحتاج نموذج رؤية حاسوبية مدرّباً على **لغة الإشارة الأمريكية ASL**، مثل نموذج MediaPipe/TensorFlow.js مخصص. كما أن WhatsApp وMessenger وInstagram خدمات خارجية؛ الأزرار تفتح المشاركة أو الروابط ولا تنتحل تكاملها الرسمي.
