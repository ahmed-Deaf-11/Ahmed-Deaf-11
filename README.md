# Ahmed-Deaf-11

واجهة ويب عربية لمساعدة الصم وضعاف السمع على التواصل:

- كتابة رسالة مباشرة من لوحة المفاتيح أو Google Keyboard.
- تحويل الكلام إلى نص عبر Speech Recognition.
- قراءة الرسالة بصوت عالٍ.
- تشغيل مقاطع إشارات ASL بالتتابع من مجلد `videos/`.
- تشغيل كاميرا الجهاز مع واجهة جاهزة لإضافة نموذج رؤية حاسوبية.
- مشاركة النص عبر WhatsApp وMessenger وInstagram أو قائمة مشاركة الجهاز.

## التشغيل

شغّل المشروع عبر GitHub Pages أو خادماً محلياً يدعم HTTPS، ثم افتح `index.html` واسمح بالميكروفون والكاميرا. أضف ملفات MP4 مرخّصة إلى مجلد `videos/`، مثل:

```text
videos/hello.mp4
videos/thanks.mp4
videos/yes.mp4
videos/no.mp4
```

## ملاحظة عن الترجمة المباشرة من الكاميرا

النسخة الحالية تعرض بث الكاميرا وتتحقق من صلاحية تشغيلها، لكنها لا تدّعي ترجمة ASL تلقائياً. الترجمة الحقيقية تحتاج نموذج رؤية حاسوبية مدرّباً على بيانات ASL (مثل MediaPipe/TensorFlow.js مع مصنّف مخصص)، مع مراعاة اختلافات الإضاءة والحركة واللهجات الإشارية. لا تستخدم هذه الواجهة بديلاً عن مترجم محترف.

## المشاركة

WhatsApp يدعم تمرير النص عبر رابط المشاركة. Messenger وInstagram يطبقان قيوداً على الإرسال المباشر من المتصفح؛ لذلك تفتح الأزرار التطبيق أو الصفحة، بينما تستخدم المشاركة الأصلية في الهاتف عند توفرها.
